# Разработка J.A.R.V.I.S.

Этот репозиторий хранит только **исходники**. Рабочая установка, из которой всё запускается, — `C:\LLM`
(там же лежат скачанные программы, модели, ключи, история сессий — их здесь нет и быть не должно).

## Как вести изменения

1. Правьте и проверяйте в `C:\LLM` (лаунчер, агент, бот работают оттуда).
2. Перенесите исходники сюда и закоммитьте:

   ```powershell
   cd C:\Projects\JARVIS
   .\sync.ps1
   git add -A
   git commit -m "что изменилось"
   ```

   `sync.ps1` копирует только файлы из своего списка и перед копированием проверяет каждый на ключи,
   токены и личные пути. Если что-то найдено — ничего не копируется, в консоли видно, какой файл виноват.
3. Откатить рабочую установку к версии из репозитория: `git checkout <коммит>` (или нужную ветку), затем
   `.\sync.ps1 -ToLive` и перезапустить лаунчер и агента. Список локальных моделей в `C:\LLM` при этом сохраняется.

## Что где

| Папка | Что внутри |
|---|---|
| `launcher/` | Лаунчер: `server.js`, модули `lib/`, интерфейс `ui/`, мод Windhawk `mods/`, скрипты `tools/`, иконки |
| `agent/plugins/` | Плагины агента: тема и голос (`dsh-jarvis`), пресеты для Telegram-агента (`jarvis-acp-presets`) |
| `agent/home/` | Пресеты режимов, навыки, инструкции и настройки агента (без ключей и сессий) |
| `agent/rules.yaml` | Правила доступа агента (в рабочей системе — `C:\Projects\.dsh\rules.yaml`) |
| `tools/` | Инструмент картинок для агента (`mcp/comfyui`), Telegram-бот, скрипты Blender и CapCut |
| `installer/` | Установщик для друзей: `Installer.cs`, `ui.xaml`, сборка `build.ps1` |
| `docs/` | Темы оформления Windows |
| `hud/` | Исходники живых обоев (Rust) |

Сборка установщика — `installer\build.ps1` из рабочей установки `C:\LLM` (ей нужны скачанные программы и модели,
которых в репозитории нет).
