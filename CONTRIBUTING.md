# Contributing · Как помочь проекту

**English.** Bug reports, ideas and pull requests are welcome.

- **Found a bug?** Open an [issue](../../issues/new/choose) with your Windows version, GPU/RAM and the log from
  the launcher's **System → Logs** tab. Never paste API keys or Telegram tokens.
- **Have an idea?** Start a thread in [Discussions](../../discussions) or open a feature request.
- **Pull requests:** keep them small and focused, test on Windows 10/11, follow the style of the surrounding code.
  The working install lives in its own folder (e.g. `C:\LLM`); `sync.ps1` copies the sources into this repo and
  checks them for secrets — see [РАЗРАБОТКА.md](РАЗРАБОТКА.md).

**Русский.** Сообщения об ошибках, идеи и pull request'ы приветствуются.

- **Нашли ошибку?** Создайте [issue](../../issues/new/choose): версия Windows, видеокарта и ОЗУ, журнал с вкладки
  лаунчера **«Система» → «Журналы»**. Никогда не вставляйте ключи API и токены Telegram.
- **Есть идея?** Напишите в [Discussions](../../discussions) или создайте запрос на улучшение.
- **Pull request'ы:** небольшие и по одной теме, проверенные на Windows 10/11, в стиле окружающего кода.
  Рабочая установка — в своей папке (например, `C:\LLM`); `sync.ps1` переносит исходники в репозиторий
  с проверкой на секреты — см. [РАЗРАБОТКА.md](РАЗРАБОТКА.md).
