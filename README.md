# J.A.R.V.I.S. — всё в одной папке

Запуск: ярлык **J.A.R.V.I.S.** на рабочем столе (`launcher\start.ps1`). Лаунчер открывается отдельным окном
и управляет всем остальным: агентом, локальной моделью и обоями HUD.

| Папка | Что внутри |
|---|---|
| `launcher\` | Лаунчер: `server.js` (ядро на Node.js, порт 3190), `ui\` (интерфейс), `start.ps1`, иконки |
| `agent\home\` | Настройки агента DeepSeek Harness (бывший `~\.dsh`; там оставлена ссылка-junction сюда) |
| `agent\plugins\dsh-jarvis\` | Плагин голосового режима «Джарвис» |
| `runtime\dsh\` | Сам DeepSeek Harness (dsh + pnpm) |
| `runtime\llama.cpp\` | llama-server для локальной модели (CUDA) |
| `runtime\uv\` | Python 3.12 и кэш uv для MCP-серверов и голоса (edge-tts) |
| `models\` | Файлы локальной модели (`*.gguf`) — ставятся и удаляются из лаунчера |
| `tools\mcp\` | MCP-серверы: Playwright, VectCutAPI (CapCut) |
| `tools\blender\` | Запуск Blender с MCP-сервером и установка аддона |
| `hud\` | Живые обои J.A.R.V.I.S. HUD 2.0 (исходники Rust + `JarvisHUD2.exe`) |
| `data\` | Логи и профили окон: `agent\`, `model\`, `launcher\` |
| `docs\` | Инструкции (Premiere, FL Studio) и патч VectCutAPI |

Проекты агента лежат отдельно, в `C:\Projects`. Настройки обоев хранятся там, где их ищет сам HUD:
`%APPDATA%\JarvisHUD2\config.json` — лаунчер меняет именно этот файл.

## Как устроено

- **Агент**: лаунчер запускает `dsh web`, берёт ссылку с токеном из вывода и открывает её окном Edge.
  Закрыли окно агента — агент останавливается.
- **Тема Джарвиса в агенте**: `agent\plugins\dsh-jarvis\lib\theme.css` переопределяет цветовые токены тёмной темы
  Harness и рисует HUD-рамку поверх окна (клики не перехватывает). Включается переключателем в лаунчере
  (файл `data\agent\jarvis-theme.json`), применяется на лету. Цвет акцента берётся из настроек обоев HUD.
- **Оформление Windows** (вкладка «Оформление» → «Windows»): панель задач Джарвиса — лаунчер сам ставит портативный
  Windhawk 1.7.3 (открытый код, GPL-3.0) в `tools\windhawk`, компилирует мод «Windows 11 Taskbar Styler» и пишет тему
  `docs\taskbar-jarvis.yaml` в его настройки (`launcher\lib\windhawk.js`). Так же оформлены меню «Пуск», центр уведомлений,
  Проводник (`docs\*-jarvis.yaml`) и все окна — собственным модом `launcher\mods\jarvis-window-colors.wh.cpp`
  (тёмно-синий заголовок, голубая рамка; папки игр исключены из-за античитов); и иконки в стиле Джарвиса
  (`launcher\tools\make-win-icons.ps1` рисует, `launcher\tools\win-style.ps1` применяет/откатывает с резервной копией).
- **Локальные модели** (`launcher\lib\`): `hardware.js` определяет видеокарту, ОЗУ и движок; `hf.js` ищет GGUF-модели
  на Hugging Face и разбирает варианты сжатия; `models.js` ведёт реестр `models\registry.json`, качает (curl с докачкой +
  SHA-256), оценивает «быстро / нормально / медленно / не влезет» для этого ПК и запускает `llama-server` на порту 8081
  с контекстом 16K–128K; `harness.js` прописывает установленные модели в агента (блок в `agent\home\cordis.patch.yml`),
  контекст в агенте всегда равен запущенному. Каждая модель лежит в своей папке внутри `models\`.
- **Выключение**: если окно лаунчера закрыто и агент не работает, ядро лаунчера само выгружает модель и завершается.
  Кнопка ⏻ в лаунчере останавливает агента и модель; обои продолжают работать.
